# Калькулятор рентабельности

Калькулятор расчёта маржинальной прибыли (MP%) и маржинального дохода (МД) по сделкам. Работает полностью в браузере, без сервера и внешних зависимостей.

## Возможности

- **15 позиций** для расчёта сделки
- **Взаимосвязанные выпадающие списки**: Класс → Наименование
- **3 сценария расчёта**: прайс, клиент (со скидкой/наценкой), клиент + дилер
- **Валютная конвертация**: РОССИЯ / БЕЛАРУСЬ (₽ → €) и Общий (€)
- **Ручной ввод TVC** с визуальной подсветкой изменённых значений
- **Двунаправленный ввод**: цена сделки ↔ процент скидки/наценки
- **Итоговая строка**: сумма Кол-во, МД, Выручка, Отклонения, взвешенный MP%
- **Экспорт в Excel** (.xlsx, через SheetJS)
- Деплой на **GitHub Pages** — работает из коробки

## Быстрый старт

### Вариант 1: GitHub Pages (рекомендуется)

1. Клонируйте или форкните репозиторий
2. Данные уже сгенерированы в `data/api-data.json` — просто откройте `index.html`
3. Для деплоя на GitHub Pages:
   - Settings → Pages → Source: `main` branch, `/ (root)`
   - Готово: приложение доступно по адресу `https://<username>.github.io/profitability-calculator/`

### Вариант 2: Локальный запуск

1. Клонируйте репозиторий
2. Откройте `index.html` в браузере (двойной клик или `Ctrl+O`)

Для обновления данных из CSV:

```bash
# Поместите свежие CSV-файлы в sample-data/ (или укажите свои пути)
python3 scripts/convert-csv.py

# Или с явными путями:
python3 scripts/convert-csv.py \
  --price /путь/к/Кальлятор\ РМ\ Прайс.csv \
  --tvc /путь/к/Кальлятор\ РМ\ TVC.csv \
  --output data/api-data.json
```

## Формат исходных CSV

### Прайс-лист (`Кальлятор РМ Прайс.csv`)

Разделитель: `;` или `,` (определяется автоматически)

| Столбец | Описание |
|---------|----------|
| Прайс | Регион (РОССИЯ, БЕЛАРУСЬ, Общий) |
| Класс ТМЦ | Класс товара |
| ТМЦ кратко | Краткое наименование |
| ТМЦ | Полное наименование |
| Код | Код товара |
| Цена | Цена в валюте региона |

### TVC-список (`Кальлятор РМ TVC.csv`)

| Столбец | Описание |
|---------|----------|
| Класс ТМЦ | Класс товара |
| ТМЦ кратко | Краткое наименование |
| TVC | Целевая себестоимость в € (запятая = десятичный разделитель) |
| ТМЦ | Полное наименование |
| Код | Код товара |

## Логика расчёта

- **Цена в €** = Цена в локальной валюте / Курс (для РОССИЯ/БЕЛАРУСЬ), иначе = Цена напрямую
- **Цена сделки** = Цена × (1 + Скидка/Наценка %)
- **МД прайс** = (Цена в € − TVC) × Кол-во
- **МД клиент** = (Цена сделки в € − TVC) × Кол-во
- **МД кл.+дил.** = (Цена сделки × (1 − Скидка дилера %) − TVC) × Кол-во
- **Выручка** = Цена сделки в € × Кол-во
- **MP%** = (Цена в € − TVC) / Цена в € × 100

## Обновление данных

При обновлении прайс-листа в Google Sheets:

1. Экспортируйте два листа как CSV (UTF-8)
2. Сохраните в `sample-data/`
3. Запустите: `python3 scripts/convert-csv.py`
4. Закоммитьте изменения: `data/api-data.json`
5. Запушьте в GitHub — GitHub Pages обновится автоматически
